## 🚀 Como Testar as Paletas

### Para aplicar a Opção 1 (Atual - Ocean Blue):
✅ Já está aplicada! É a paleta atual no arquivo `_light.scss`

### Para aplicar a Opção 2 (Emerald Green):
Substitua as variáveis de cores no início do arquivo `src/app/styles/themes/_light.scss`:
```scss
:root.theme-light {
  --primary: #059669;
  --primary-rgb: 5, 150, 105;
  --secondary: #10b981;
  --accent: #f59e0b;
  --accent-secondary: #d97706;
  --text-color: #064e3b;
}
```

### Para aplicar a Opção 3 (Rose Pink):
Substitua as variáveis de cores no início do arquivo `src/app/styles/themes/_light.scss`:
```scss
:root.theme-light {
  --primary: #db2777;
  --primary-rgb: 219, 39, 119;
  --secondary: #a855f7;
  --accent: #06b6d4;
  --accent-secondary: #8b5cf6;
  --text-color: #831843;
}
```
